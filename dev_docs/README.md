# Development Documentation

Internal development documents for the CPG-to-ACP project. Not intended for user-facing documentation (see `docs/` for that).

**NOTE:** Everything in this folder should be viewed as a point-in-time reference. Files may not be updated as development moves forward and new decisions are made.

## Structure

| Directory | Contents |
|-----------|----------|
| `design/` | Component and contract design documents |
| `spikes/` | Technical investigations and decision records |
| `learning/` | Lessons learned — pitfalls and hard-won knowledge (e.g., deploying on OpenShift with MaaS, OpenShell, SonataFlow) |
| `ui/` | UI/UX spikes and wireframes (Phase 4) |

Top-level files: release plan, project plan (historical), project proposal, and intro deck.

- [`release-plan.md`](release-plan.md) — the November 2026 release plan, organised by track with owners; adopted by the team on November 5, 2026. Start here for current work.
- [`project-plan.md`](project-plan.md) — the phase plan through Phase 3.3; historical since November 5, 2026.

- [`design/automation-design.md`](design/automation-design.md) — point-in-time automation design copy, captured 2026-10-22; errata E1–E40 are appended as written.
